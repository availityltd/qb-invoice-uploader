Connect your QuickBooks company

This page reads your invoices so you can review them. Nothing changes until you press a button.

Take a backup first. Deleting an invoice in QuickBooks cannot be undone. Go to QuickBooks → Settings → Export data before using any button here. Use View list to check exactly what will go before you press delete.

01 Scan

Invoices are grouped by their digits, so #91306999 and 91306999 land together — and so do two copies written exactly the same way.

02 What was found

0 Same order as # and plain — neither paid Amounts match and no payment is attached to either. Removing one of them leaves the order intact.
0 Same order — the # one is paid The payment sits on the # version, so the plain one is the spare.
0 Same order — the plain one is paid The payment sits on the plain version, so the # one is the spare.
0 Same number more than once — one copy is paid Written the same way, but there twice or more. The paid copy stays; the unpaid extras go.
0 Same number more than once — none paid All copies are unpaid, so one is kept and the rest removed.
0 Plain invoices with no twin Nothing is duplicated here. Adding the # lines them up with your older records. Nothing is deleted.
Left for you to look at
0 Both copies carry a payment Deleting either one breaks a payment record. Open these in QuickBooks and decide there.
0 Same number more than once — every copy paid Every copy has money against it. These need a decision in QuickBooks.
0 Same number but different amounts These are probably not the same order at all, so nothing here is touched.

03 What was changed

Paid invoices are never removed by these buttons. A payment in QuickBooks is attached to a particular invoice, so removing that invoice leaves the payment with nothing to sit against. Anything carrying money is put in the section at the bottom for you to handle in QuickBooks.

Scan again after a run so the counts reflect what is actually in QuickBooks now.
